# Gemeinsame Referenzen

Diese Werte sind **fiktive Teamreferenzen für das Experiment**, keine gemessenen
Erfahrungswerte. Es gilt dieselbe Definition of Done. Eine Nutzung von KI beim
Entwickeln ist in den Beispielwerten bereits mitgedacht.

| Points | Referenz      | Umfang                                           |
| ------ | ------------- | ------------------------------------------------ |
| 2      | Statusfilter  | Bestehende Liste + API, UI-Auswahl und Tests     |
| 3      | Kunden-CSV    | Bis 1.000 Zeilen, Admins, UI/API und CSV-Tests   |
| 8      | ERP-Anbindung | Neue Schnittstelle, Jobs, Retries und Monitoring |

Statusfilter und Kundenexport sind in der Demobasis ausführbar. Die ERP-Anbindung
ist eine beschriebene Vergleichsreferenz; sie ist nicht Teil dieses Repositories.
